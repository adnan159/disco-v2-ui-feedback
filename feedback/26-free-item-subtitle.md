# Reward → "Free or cheaper item": subtitle should be "BOGO, Gift"

## Issue

**Steps:** Campaigns → Discounts → Buy more, save more → Reward → Other rewards → Free or cheaper item

![Free or cheaper item subtitle](../screenshots/free-item-subtitle.png)

The card's subtitle reads **"BOGO, buy X get Y, gifts"** (marker 1). It's long and repeats itself, since "buy X get Y" is a kind of BOGO.

## Suggestion

Change the subtitle to **"BOGO, Gift"**.
